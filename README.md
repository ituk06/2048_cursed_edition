# Логическая браузерная игра «2048»

Данный репозиторий содержит программный продукт и сопровождающую техническую документацию, подготовленные для проведения тестирования.

## ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)

**1. Введение**
Программный продукт представляет собой логическую браузерную игру «2048». Область применения продукта — развлекательная сфера, тренировка логического мышления и внимательности пользователей[cite: 1].

**2. Основания для разработки**
Основанием для разработки является выполнение практической работы №1 по дисциплине «Тестирование программного обеспечения» (или укажите ваше точное название)[cite: 1].

**3. Назначение разработки**
Разработка предназначена для предоставления пользователю интерактивной математической головоломки[cite: 1]. Главная задача программы — обеспечить корректную генерацию игрового поля, обработку пользовательского ввода и подсчет очков в реальном времени.

**4. Требования к программе**
* **Функциональные требования:**[cite: 1]
  * Игра должна генерировать поле размером 4x4 клетки.
  * При старте игры на пустом поле должны случайным образом появляться две плитки номиналом «2» (с вероятностью 90%) или «4» (с вероятностью 10%).
  * Пользователь должен иметь возможность сдвигать все плитки на поле с помощью клавиш со стрелками (Вверх, Вниз, Влево, Вправо).
  * При столкновении двух плиток с одинаковым номиналом они должны объединяться в одну плитку с номиналом, равным их сумме.
  * За каждое объединение пользователю должны начисляться очки, равные номиналу новой (объединенной) плитки.
  * Игра должна заканчиваться (Game Over), если все 16 клеток заполнены и нет доступных ходов для объединения.
* **Требования к надежности:** Программа должна быть устойчива к некорректным нажатиям клавиш (нажатие любых кнопок, кроме стрелок, должно игнорироваться)[cite: 1].
* **Условия эксплуатации:** Программа должна запускаться на персональных компьютерах без необходимости установки дополнительных серверных модулей[cite: 1].
* **Совместимость:** Продукт должен корректно работать в современных веб-браузерах (Google Chrome, Mozilla Firefox, Safari, Edge) с включенным JavaScript[cite: 1].

**5. Требования к интерфейсу**
* Интерфейс должен содержать игровое поле 4х4 клетки, счетчик текущих очков (Score), счетчик лучшего результата (Best) и кнопку «New Game»[cite: 1].
* Кнопка «New Game» должна перезапускать игру, обнуляя счет и очищая поле[cite: 1].
* При достижении плиткой номинала 2048 должно появляться уведомление о победе.
* При отсутствии ходов должно появляться уведомление об окончании игры.

**6. Критерии приемки**
Продукт считается готовым, если он успешно запускается в браузере, а его функциональность соответствует всем пунктам, описанным в разделе 4 данного ТЗ[cite: 1]. 

**7. Требования к документации и описание запуска**
Вместе с программным продуктом поставляется «Руководство пользователя» (см. раздел ниже)[cite: 1]. 
*Описание запуска:* Исполнение программы не является нетривиальным[cite: 1]. Для запуска необходимо клонировать или скачать репозиторий на локальный компьютер и открыть файл `index.html` в любом современном веб-браузере.

**8. Порядок контроля и приемки**
Контроль качества осуществляется командой тестировщиков путем проведения функционального тестирования методом «черного ящика» на основе данного ТЗ[cite: 1]. 

**9. Этапы и сроки разработки**
* Этап 1: Подготовка окружения и репозитория (Сентябрь 2026 г.)[cite: 1].
* Этап 2: Написание технической документации (Сентябрь 2026 г.)[cite: 1].
* Этап 3: Подготовка программного продукта к тестированию (Сентябрь 2026 г.)[cite: 1].

## РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ

Данный раздел представляет собой пользовательскую документацию, предназначенную для конечных пользователей с целью облегчения освоения программного продукта[cite: 1].

### 1. Описание программы
«2048» — это математическая головоломка. Ваша цель — сдвигая плитки по игровому полю, получить плитку с номиналом «2048».

### 2. Установка и запуск
Игра не требует установки дополнительных программ. Для запуска выполните следующие действия:
1. Скачайте папку с файлами игры (или склонируйте репозиторий).
2. Найдите в корневой папке файл `index.html`.
3. Откройте этот файл двойным кликом (он откроется в вашем браузере по умолчанию) или перетащите его в окно открытого браузера.

### 3. Управление в игре
* Используйте клавиши **Стрелка Вверх**, **Стрелка Вниз**, **Стрелка Влево**, **Стрелка Вправо** на клавиатуре для перемещения плиток.
* При нажатии стрелки все плитки на поле сдвигаются в указанном направлении до упора.
* Если две плитки с одинаковым числом сталкиваются во время движения, они сливаются в одну, а их значения суммируются (например, 2+2=4, 4+4=8 и так далее).
* После каждого хода на случайной пустой клетке появляется новая плитка.

### 4. Интерфейс
* **Score:** Отображает ваши текущие очки. Очки даются за каждое успешное слияние плиток.
* **Best:** Отображает лучший результат за все время.
* **Кнопка «New Game»:** Позволяет прервать текущую партию и начать игру заново с нулевым счетом.
